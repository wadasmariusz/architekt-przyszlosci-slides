Definicja

Elementy operują na tych samych danych — mają wspólny kontekst.

OrderModule.cs
public class OrderModule {
  bool Validate(Order order) walidacja
  decimal CalculateTotal(Order order) wartość
  void ApplyDiscount(Order order) rabat
  Document GenerateConfirmation(Order order) potwierdzenie
}

Wszystkie metody pracują na tym samym obiekcie Order — wspólny kontekst danych.

Wyróżnik

To pierwszy poziom, w którym grupowanie ma silne uzasadnienie merytoryczne — wspólne dane.
