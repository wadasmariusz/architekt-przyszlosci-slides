Spójność logiczna Logical

Definicja

Elementy robią rzeczy „logicznie podobne", ale nie współpracują ze sobą.

Validators.cs
public class Validators {
  bool ValidateAddress(Address a) adres
  bool ValidatePhone(string phone) telefon
  bool ValidateZipCode(string zip) kod poczt.
  bool ValidatePesel(string pesel) PESEL
}

Łączy je tylko słowo validate — inne dane, inne reguły, inne konteksty.

Analogia do zapamiętania

Jak wrzucenie do jednego pudełka wszystkich niebieskich rzeczy w domu.

pudełko: „niebieskie"
skarpetki
długopis
książka

Kryterium jest, ale bezużyteczne — nikt nie szuka rzeczy „po kolorze".
