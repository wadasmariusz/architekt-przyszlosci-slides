Spójność funkcyjna Functional

Wszystkie elementy współpracują, by zrealizować jedną, dobrze zdefiniowaną funkcję. Żadnego nie można usunąć bez zniszczenia tej funkcji.

PaymentAuthorization.cs
public class PaymentAuthorization {
  bool ValidateCard(Card card) walidacja karty
  GatewayResponse CallGateway(Payment p) bramka
  AuthResult HandleResponse(GatewayResponse r) odpowiedź
  void LogTransaction(AuthResult r) logowanie
}

Wszystko podporządkowane jednemu celowi — usuń jedną metodę i autoryzacja przestaje działać.
