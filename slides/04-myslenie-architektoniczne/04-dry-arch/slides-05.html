Wiedza w kontekście

Trzy konteksty, trzy definicje „User"

Authentication Service
tożsamość & dostęp
class User {
email
passwordHash
roles
accountStatus
}
Profile Service
osoba & preferencje
class User {
displayName
avatar
notificationPrefs
themePreference
}
Notification Service
kanał komunikacji
class User {
emailAddress
language
timezone
optInStatus
}
Trzy klasy o tej samej nazwie ≠ naruszenie DRY. To trzy osobne definicje wiedzy.
