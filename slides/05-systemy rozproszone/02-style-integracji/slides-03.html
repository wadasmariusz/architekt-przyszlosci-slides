Coupling

Na czym opiera się zależność?

Współdzielone
  • Format pliku - CSV, JSON, Parquet…
  • Schemat i nazwy kolumn - kolejność, typy
  • Kodowanie znaków - UTF-8, Windows-1250
  • Lokalizacja pliku - ścieżka, bucket, nazwa
  • Harmonogram - kiedy produkować, kiedy czytać
Niezależne
  • Język programowania - Java po jednej, Python po drugiej
  • Baza danych - różne silniki, różne schematy
  • Środowisko uruchomieniowe - runtime, wersje, OS
  • Dostępność w czasie rzeczywistym - moduły mogą żyć niezależnie

Jeden moduł nie musi nawet wiedzieć, kto czyta jego pliki.
